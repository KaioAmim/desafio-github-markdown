# 📚 Conceitos Básicos de Markdown
 
Este arquivo apresenta alguns dos principais recursos utilizados do **Markdown** ensinados no curso de github da DIO.
 
## 📝 Títulos
 
Para criar títulos, utilizamos o símbolo `#`.
 
```markdown
# Título 1
## Título 2
### Título 3
#### Título 4
```
 
## 📋 Listas
 
### Lista não ordenada
 
```markdown
- HTML
- CSS
- JavaScript
- PHP
```
 
Resultado:
 
* HTML
* CSS
* JavaScript
* PHP
 
### Lista ordenada
 
```markdown
1. HTML
2. CSS
3. JavaScript
4. PHP
```
 
Resultado:
 
1. HTML
2. CSS
3. JavaScript
4. PHP
 
### Sublista
 
```markdown
- Front-end
  - HTML
  - CSS
  - JavaScript
- Back-end
  - PHP
  - MySQL
```
 
Resultado:
 
* Front-end
 
  * HTML
  * CSS
  * JavaScript
* Back-end
 
  * PHP
  * MySQL
 
## 🔗 Links
 
Para adicionar um link:
 
```markdown
[Titulo](Url)
```
 
Exemplo:
 
[GitHub](https://github.com)
 
## 🖼️ Imagens
 
Para adicionar uma imagem:
 
```markdown
![Descrição da img](link da img)
```

Resultado:
 
![Foto exemplo](https://wallpapercave.com/wp/wp12626768.jpg)

## 📊 Tabelas
 
Para criar uma tabela:
 
```markdown
| Linguagem | Tipo | Uso |
|-----------|------|-----|
| HTML | Front-end | Estrutura |
| CSS | Front-end | Estilização |
| JavaScript | Front-end | Interatividade |
| PHP | Back-end | Servidor |
```
 
Resultado:
 
| Linguagem  | Tipo      | Uso            |
| ---------- | --------- | -------------- |
| HTML       | Front-end | Estrutura      |
| CSS        | Front-end | Estilização    |
| JavaScript | Front-end | Interatividade |
| PHP        | Back-end  | Servidor       |
 
## 💻 Código
 
Também podemos adicionar trechos de código:
 
```javascript
console.log("Olá, mundo!");
```
 
## ✨ Formatação de texto
 
Podemos utilizar:
 
* *Negrito*
* _Itálico_
 
Exemplo:
 
```markdown
**Negrito**
 
_Itálico_
 
```
 
## 📌 Citação
 
Para criar uma citação:
 
```markdown
> "Citação."
```
 
Resultado:
 
> "Citação."
 
## ☑️ Checklist
 
Também podemos criar listas de tarefas:
 
```markdown
- [x] Criar o arquivo Markdown
- [x] Adicionar títulos
- [x] Adicionar listas
- [ ] Adicionar mais exemplos
```
 
Resultado:
 
* [x] Criar o arquivo Markdown
* [x] Adicionar títulos
* [x] Adicionar listas
* [ ] Adicionar mais exemplos
 
## 🚀 Conclusão
 
O Markdown é uma linguagem simples e prática para criar documentos formatados. No GitHub, ele é muito utilizado principalmente em arquivos `README.md` para apresentar projetos, documentações e informações importantes.
